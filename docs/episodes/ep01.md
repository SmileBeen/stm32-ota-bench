# EP01 왜 이 프로젝트를 하나

## 이번 회차 목표
이 시리즈에서 무엇을 만들고, 왜 그게 펌웨어 개발자에게 필요한지 정리해요. 부품 없이 보는 회차예요.

## 다루는 내용
- 펌웨어 채용 공고에서 자주 나오는 요구: 부트로더, OTA, 보안, TLS·인증서
- 원격 업데이트와 보안이 의무가 되는 흐름 (EU CRA)
- 전체 흐름: 현장 로그(B) → 연구소 재현(A) → 서명 OTA(C)
- 9회차 로드맵과 V-모델

## 개념 더 보기
- **V-모델**: 왼쪽에서 정의한 문서마다 오른쪽에 짝이 되는 시험이 있는 개발 흐름
- **추적성**: 요구사항 → 설계 → 코드 → 시험을 ID로 이어 빠진 곳을 찾는 것
