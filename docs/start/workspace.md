# 촬영·작업 환경

영상을 찍으면서 작업하는 책상 구성이에요. 따라 하면서 화면을 녹화하거나 찍고 싶은 분께 참고가 될 거예요.

## 책상
- 벽에 붙인 흰 책상. 왼쪽은 측정기, 가운데는 시험대, 오른쪽은 노트북과 납땜(창문 쪽, 환기).
- 시험대 자리에 **회색 무광 매트**. 배선 색이 잘 보이고 조명 반사가 적어요.

## 조명
- 책상 양쪽 앞에서 45°로 LED 스탠드 2개, 주광색(5000~5600K).
- 천장등만 쓰면 몸과 손 그림자가 책상에 생겨요.

## 카메라
- 책상 뒤쪽 모서리에 클램프식 오버헤드 암, 폰을 상판 위 55~60cm에.
- DroidCam으로 폰 카메라를 OBS에 바로 연결해요. 카메라 앱 화면이 안 찍혀요.

## OBS 장면
| 장면 | 구성 |
|---|---|
| 나란히 | 왼쪽 브라우저(그림·배선도), 오른쪽 탑다운 카메라 |
| 실물 크게 | 카메라 전체 + 작은 그림 |
| 그림 크게 | 브라우저 전체 |
| 코드 | VS Code + 작은 카메라 |
