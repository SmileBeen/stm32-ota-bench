# 부품 목록

판 2장(현장 420×297, 연구소 400×250, MDF 9mm)에 올라가는 부품이에요. 번호는 [시험대 조립 가이드](../bench/assembly.html)의 번호와 같아요.

!!! tip "같은 부품이 없을 때"
    Nucleo 보드는 같은 계열(G4, F4)이면 대부분 따라 할 수 있어요. 바꾼 부품은 회차 문서의 "대체 부품" 칸을 확인하세요.

| 번호 | 부품 | 역할 |
|---|---|---|
| 1 | MDF 판 · 스탠드오프 | 모든 부품의 바닥. 보드는 스탠드오프 위에, 작은 모듈은 양면 폼테이프로 붙여요. |
| 2 | 전원 입구 (연구소) | 어댑터 DC 플러그를 받아서 퓨즈를 거쳐 단자대로 보냅니다. |
| 3 | 배리어 단자대 12P (연구소) | 전원 분배 버스. 한 번호의 왼쪽 나사와 오른쪽 나사는 안에서 이어져 있어요. 왼쪽 = 입력, 오른쪽 = 출력으로 정합니다. |
| 4 | 릴레이 4ch (HK4100F) | F746이 DUT 5V(CH1)와 모터 12V(CH2)를 끄고 켭니다. CH3·CH4는 예비. |
| 5 | INA226 (DUT 전류) | DUT로 가는 5V의 전류·전압을 I2C로 F746에 알려줘요. |
| 6 | 2x5 리본 케이블 | 시험대(J2)와 DUT(J1)를 잇는 표준 케이블. 5V·GND·NRST·BOOT0·SWD·UART·CAN이 다 들어가요. |
| 7 | J2 어댑터 (시험대 쪽) | 리본을 받아서 F746 핀, 단자대, CANable로 나눠주는 보드. B줄은 로직분석기 탭이에요. |
| 8 | J1 어댑터 (DUT 쪽) | 리본을 받아서 G474 모포 핀으로 나눠주는 보드. |
| 9 | STM32F746G-DISCO (시험대) | 자작 시험대의 두뇌. DUT 전원 차단, 리셋, 부트 모드, UART 콘솔, 전류 측정, LCD 표시. |
| 10 | G474 재현 노드 (DUT) | 현장에서 난 고장을 재현하고 고친 펌웨어를 시험하는 대상 보드. |
| 11 | CAN Pal (DUT 쪽) | G474의 CAN 로직 신호를 CANH/CANL 차동 신호로 바꿔요. |
| 12 | CANable 2.0 | PC가 CAN 버스를 직접 보고, 메시지를 넣어볼 수 있게 해요(SocketCAN·slcan). |
| 13 | STLINK-V3SET | 누클레오가 아닌 보드(옛 장비 리트로핏, 커스텀 보드)를 SWD로 굽고 디버깅할 때만 써요. |
| 14 | D4184 MOSFET 모듈 (연구소) | 모터 − 쪽을 GND로 끊었다 이었다 하는 로우사이드 스위치. PWM으로 속도 조절. |
| 15 | INA240 전류 증폭기 + 션트 (연구소) | 모터 전류를 PWM 중에도 깨끗한 전압 파형으로 바꿔 ADC로 보냄. 미니 오실로스코프 역할. |
| 16 | 12V 감속 모터 + 브래킷 (연구소) | 재현 대상 부하. 막힘·과전류·PWM 이상 같은 고장을 만들어볼 수 있어요. |
| 17 | 로직분석기 24MHz 8ch | UART, NRST, BOOT0, CAN(로직 쪽)의 타이밍을 눈으로 확인해요. |
| 18 | 전원 입구 (현장) | 연구소 판과 같은 구조. 5V 4A가 H743·노드·F103을 먹여요. |
| 19 | 배리어 단자대 12P (현장) | 현장 판 전원 분배. 점퍼는 연구소와 같아요(T1–T4 +5V, T5–T9 GND, T10 +12V). |
| 20 | 릴레이 2ch (노드 원격 리셋) | 게이트웨이가 CAN으로 지시하면 노드2가 노드1 전원을, 노드1이 노드2 전원을 잠깐 끊어 리셋해요. |
| 21 | INA226 ① (노드1 전류) | 노드1이 먹는 5V 전류·전압. 노드1이 직접 읽어 로그로 보내요. |
| 22 | INA226 ② (노드2 전류) | 노드2 5V 전류·전압. OLED와 같은 I2C 선에 나란히 물려요. |
| 23 | H743-EVAL (게이트웨이) | 현장 장비들의 로그를 모아 LAN으로 보내고, 업데이트를 받아 나눠주는 게이트웨이. LCD는 상태판. |
| 24 | DB9 어댑터 #1 (CAN) | EVAL CN3의 CAN 신호를 나사단자로 꺼내요. |
| 25 | CAN 버스 배선 | H743 → 노드1 → 노드2 한 줄(데이지 체인). 양끝에만 120Ω 종단. |
| 26 | CAN Pal ① (노드1) | 노드1의 CAN 트랜시버. 버스 중간이라 종단 OFF. |
| 27 | CAN Pal ② (노드2) | 노드2의 CAN 트랜시버. 버스 끝이라 종단 ON. |
| 28 | G474 노드1 (모터 · 파형) | 모터를 돌리고 전류 파형을 ADC로 떠서 고장 로그와 함께 CAN으로 보내요. |
| 29 | G474 노드2 (센서 · 버튼 · OLED) | 버튼 입력과 OLED 표시, 자기 전류 측정. 노드1 리셋 담당. |
| 30 | OLED 0.96" (SSD1306) | 노드2의 상태 표시. |
| 31 | 택트 버튼 ×2 | 현장 고장을 일부러 일으키는 버튼(예: 센서 이상 주입). |
| 32 | F103 옛 장비 | 업데이트가 어려운 옛 장비 역할. RS-232 콘솔로 로그를 내보내고 게이트웨이가 받아요. |
| 33 | MAX3232 + DB9 어댑터 #2 | F103의 3.3V UART를 RS-232 전압으로 바꿔 EVAL CN2에 넣어요. 실제 옛 철도 장비도 RS-232 콘솔이 흔해요. |
| 34 | D4184 MOSFET 모듈 (현장) | 모터 − 쪽을 GND로 끊었다 이었다 하는 로우사이드 스위치. PWM으로 속도 조절. |
| 35 | INA240 전류 증폭기 + 션트 (현장) | 모터 전류를 PWM 중에도 깨끗한 전압 파형으로 바꿔 ADC로 보냄. 미니 오실로스코프 역할. |
| 36 | 12V 감속 모터 + 브래킷 (현장) | 재현 대상 부하. 막힘·과전류·PWM 이상 같은 고장을 만들어볼 수 있어요. |
| 37 | USB 허브 (ORICO 7포트) | 연구소 판 전용. F746, DUT, CANable, 로직분석기, STLINK-V3SET = 5포트. |
| 38 | 개별 스위치 멀티탭 | 어댑터 5개: 5V 4A, 5V 3A, 12V ×2, 허브. 스위치로 판 전체 전원을 끊어요. |
| 39 | 공유기 · LAN | H743 게이트웨이를 인터넷(서버)에 연결. |
