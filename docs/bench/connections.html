시험대 연결 근거표

데이터시트 회로도처럼 부품마다 핀을 그리고, 같은 넷은 선으로 잇거나 같은 이름의 넷 라벨로 표시했어요. 시트 아래 "핀 설명표"를 열면 핀마다 연결 대상과 데이터시트 근거, 확인 등급이 나와요. 3D 조립 가이드와 같은 결선 데이터(153가닥)로 그렸어요.

A 원문 확인 · 매뉴얼·제품 페이지 원문과 직접 대조
B 공식 문서 기준 · 원문 표 대조 전, CubeMX·매뉴얼로 재확인
C 추정 · 모듈마다 순서·표기가 달라 실물 실크 확인
D 설계 결정 · 전원 분배·2x5 표준 단자처럼 직접 정한 연결

읽는 법: 핀 끝의 깃발 모양은 넷 라벨이에요. 이름이 같은 라벨끼리는 다른 시트에 있어도 전기적으로 연결돼 있어요. ⏚ 는 GND, ┬ 는 전원 레일이에요.
